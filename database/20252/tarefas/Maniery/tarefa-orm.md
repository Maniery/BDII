## Resumo sobre ODBC (Questão 2.b)
O ODBC (Open Database Connectivity) é uma interface padrão para acessar SGBDs. No Python, usamos o driver `psycopg2` para realizar essa comunicação direta com o PostgreSQL. Ele permite executar comandos SQL puros, oferecendo controle total sobre as transações.

## Resumo sobre ORM (Questão 2.c)
ORM (Object-Relational Mapping) é uma técnica que mapeia tabelas do banco de dados para classes na linguagem de programação. 
- **Framework utilizado:** Django ORM.
- O Django permite manipular registros do banco como se fossem objetos Python, facilitando a manutenção e legibilidade do código.
